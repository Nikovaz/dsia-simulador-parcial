M0

Definición, Evolución y Clasificación de la IA

Foco Principal en Repaso (Min 8:00 - 36:00)
▼
¿Qué es la Inteligencia Artificial? (Pregunta Fija de Examen)

Disciplina de la informática que se enfoca en crear sistemas y programas capaces de imitar la inteligencia humana mediante algoritmos y técnicas que permiten a las máquinas aprender de forma autónoma y realizar tareas complejas.

Clasificación por Capacidad
  • IA Débil (Estrecha / ANI): Especializada en una sola tarea (ej. traductor, filtro de spam). Sin conciencia ni comprensión general del entorno.
  • IA General (AGI): Capaz de razonar, aprender y adaptarse como un ser humano para múltiples dominios (en fase de investigación).
  • Superinteligencia (ASI): Hipotética; supera ampliamente al intelecto humano en todas las disciplinas y posee autoconciencia (fase teórica/filosófica).
Clasificación por Función

Sistemas Expertos (reproducen conocimiento de experto humano con base de conocimiento y motor de inferencia, ej. medicina), Sistemas de Control (regulan procesos con sensores e industria), Agentes de IA (perciben, razonan y actúan autónomamente hacia un objetivo), y Robótica (integra software con hardware/sensores para interactuar físicamente).

El Rol de N8N

La profesora aclaró: N8N no es una IA generativa de contenido; es un orquestador que conecta APIs, bases de datos y modelos LLM (ChatGPT, Claude, Gemini) para articular sistemas de agentes y automatizar flujos complejos.

Operadores y Tipos en Python (Pregunta de Examen)

En Python 3, la división simple / siempre devuelve float (ej. 25 / 4 = 6.25). La división entera // devuelve int (ej. 25 // 4 = 6), y el operador módulo % devuelve el resto (ej. 25 % 4 = 1).

Comandos Clave de Git

git init (inicia repo), git add . (stage area), git commit -m (snapshot en historial), git push origin main (sube a GitHub remoto).

M2

Análisis Exploratorio de Datos (EDA) y Medidas Estadísticas

Clases 10 y 11
▼
Técnicas Frecuentes de Análisis Univariado

Distribución de frecuencias, medidas de tendencia central (media, mediana, moda), medidas de dispersión (varianza, desviación estándar) y cuartiles con diagramas de caja (Boxplot).

Robustez de la Mediana ante Outliers

Cuando un conjunto tiene asimetría o valores atípicos (outliers), la Mediana es la medida representativa porque no se distorsiona como la Media.

Principio de Causalidad

Una alta correlación estadística entre dos variables jamás implica que una cause a la otra (asociación no es causalidad).

M3

Limpieza, Encoders, Escaladores y Distancia Euclidiana

Clases 12 y 14
▼
Encoders: One-Hot vs Ordinal

One-Hot: variables nominales sin orden (ej. Colores). Ordinal: categorías con orden natural o jerarquía de prelación (ej. Bajo, Medio, Alto).

Escaladores (Scalers)

StandardScaler: Estandariza con media 0 y desvío 1. MinMaxScaler: Lleva al rango [0, 1]. RobustScaler: Usa la mediana y el rango intercuartílico (IQR), ideal cuando el dataset contiene outliers.

¿Por qué la Distancia Euclidiana solo opera con números?

Porque involucra operaciones aritméticas (raíz cuadrada de diferencias al cuadrado) en un espacio geométrico continuo; no puede calcular distancias con palabras sin codificarlas previamente.

Data Leakage (Fuga de Información)

Incluir variables derivadas directamente del target (como calcular facturación multiplicando precio por ventas) invalida el modelo al darle la respuesta por adelantado.

M4

Modelado Supervisado: Regresión vs. Clasificación

Clases 7 y 16
▼
Los 3 Procesos Fundamentales

Entrenamiento (Train): El modelo aprende patrones. Validación: Ajuste de hiperparámetros. Prueba (Test): Evaluación final con datos nunca antes vistos para medir generalización.

Partición Estándar Train/Test

80% Entrenamiento / 20% Prueba (o 70/30). Permite entrenar con la mayoría de datos y evaluar objetivamente en el remanente.

Matriz de Confusión

La diagonal principal contiene las predicciones correctas (VP y VN). Fuera de la diagonal se ubican los errores. En salud, el Falso Negativo (FN) es el error más crítico (enfermo no diagnosticado).

M5

Aprendizaje No Supervisado: Agrupamiento (Clustering)

Clase 21
▼
Datos NO Etiquetados

El agrupamiento opera sin etiquetas previas, descubriendo similitudes y patrones geométricos en crudo (ej. K-Means con centroides, agrupamiento jerárquico).

Distancia y Similitud

A menor distancia geométrica entre puntos en el espacio multidimensional, mayor es su similitud y pertenencia al mismo cluster.
